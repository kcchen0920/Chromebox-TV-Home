# Clean TV Home for ChromeOS Chromebox

專為客廳 **ChromeOS Chromebox** 設計的極簡無廣告電視首頁系統，支援遙控器/鍵盤方向鍵（D-pad）與「兒子動圖浮在 APP 上方」跳選動態。

---

## 🌟 核心特色

1. **極致簡約、零廣告**：深色高質感 Apple TV 風格卡片佈局，不含任何搜尋引擎廣告、推薦流與促銷資訊。
2. **兒子動圖浮動跳選游標**：
   - 動圖（GIF / WebP / PNG）精準浮在當前選取 APP 卡片的**正上方**。
   - 按鍵切換時，動圖伴隨彈簧物理位移與跳躍（Jump & Bounce）特效。
   - 閒置時具有輕微的上下浮動呼吸（Hover）效果。
3. **電視遙控器 / 鍵盤操控**：
   - `←` / `→`：水平切換 APP 卡片
   - `Enter`：開啟選定 APP
   - `S`：開啟客製化設定視窗（上傳動圖、調整大小高度、增修 APP）
   - `F11`：切換全螢幕
4. **內建合成電視切換音效**：使用 Web Audio API 即時合成清脆的選單切換音，無須聯網載入音檔。

## 🚀 如何在 Chromebox 上使用

### 方式一：直接在 Chrome 瀏覽器中開啟（最快速）
1. 在 Chromebox 的 Chrome 瀏覽器中，按下 `Ctrl + O` 開啟檔案，選擇 `chromebox-tv-home/index.html`。
2. 按下鍵盤 `F11` 進入無邊框全螢幕電視模式。
3. 可以點選網址列右側的「安裝 Clean TV Home」或將其設為瀏覽器啟動頁（設定 -> 在啟動時 -> 開啟特定網頁）。

### 方式二：設為 ChromeOS 新分頁擴充功能（開機即電視）
若希望每次打開瀏覽器或開新分頁都直接是這個電視介面：
1. 在 Chrome 網址列輸入 `chrome://extensions/`。
2. 開啟右上角「開發人員模式」。
3. 點選左上角「載入未打包項目」，選擇此資料夾（內含擴充套件設定）。

---

## 👦 如何替換成兒子的動圖

1. 在首頁畫面按下鍵盤 **`S`**（或用滑鼠點擊右上角齒輪設定圖示）。
2. 在「兒子動圖跳選游標設定」區域，點擊 **「上傳兒子動圖」**，選擇您準備好的 `.gif`、`.webp` 或 `.png` 檔案。
3. 調整「動圖尺寸大小」與「浮動在 APP 上方高度」滑桿至您喜歡的位置。
4. 點選「完成並儲存」，設定會自動保存在您的 Chromebox 本地瀏覽器中！
